# Dalma

Dalma is a French insurtech offering pet health insurance for dogs and cats — reimbursing veterinary bills (up to 100%, no deductible, EUR 2,500 annual ceiling) with fast payouts (50% within 30 seconds) and unlimited veterinary teleconsultations via its mobile app. Founded in Paris and backed by Northzone, Dalma insures 60,000+ pets across France and has expanded to Germany.

Direct-to-consumer insurance brand with a member app (app.dalma.co) and a quote/subscription funnel. It publishes **no public developer API, OpenAPI definition, SDK, or developer portal** at this time, so most API artifacts are not applicable (absence recorded, never fabricated).
